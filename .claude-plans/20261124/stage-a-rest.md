# stage-a-rest — A단계 3~8 (최소 범위로 완성)

## 목표

스펙 v0.2 A단계의 남은 항목을 순서대로 완성한다. 사용자 피드백 원칙: **사용성이 복잡해지지 않게 최소 범위로**, 단계를 끝까지 완성한 뒤 사용자가 써보고 피드백.

## 범위 (각 항목 최소안)

| # | 항목 | 최소 범위 | 넣지 않는 것 |
|---|---|---|---|
| 3 | 되돌리기 | 대화 응답마다 "파일 N개 바뀜 · 되돌리기" 한 줄. 응답 전후를 앱 데이터의 숨긴 저장소에 기록(사용자 폴더에 아무것도 만들지 않음). 되돌릴 때 그 뒤 사용자가 고친 파일은 건너뛰고 알림 | diff 보기 화면 |
| 4 | 쉬운 말 승인 | 권한 카드에 쉬운 설명(설치·삭제·내려받기·실행 등)과 주의 표시, 원래 명령은 "자세히"로 접기. 팀원 권한은 3단계 선택(읽기만 / 문서 수정 / 명령 실행까지) | 권한 규칙 편집기 |
| 5 | 팀원 기억 | 팀원별 요약 노트(시스템 프롬프트에 주입, 크기 상한). 작업 보고의 "기억할 점"을 모델 호출 없이 노트에 추가. 팀 화면에서 보기·고치기 | 상세 이력 검색 |
| 6 | 분야별 팀 | 팀(개발·문서·법률·디자인·자동화·조사) 템플릿과 팀 묶음 표시, PM 팀 요약에 팀명. 법률 결과물 고지 | 팀 리더 |
| 7 | 사장 캐릭터 | 사무실 사장 자리·캐릭터, 답을 기다리는 요청 수 표시(클릭 시 대화·작업으로 이동), 사장 꾸미기(이름·외형·색) | 결재 화면 |
| 8 | 설치·로그인 안내 | 첫 화면에서 설치 여부·로그인 상태(`claude auth status`, 로그인 여부만 읽음) 점검, 설치 명령 실행 버튼(공식 설치 스크립트), 로그인 버튼(`claude auth login`) | 자동 업데이트 관리 |

## 확인한 사실

- `claude auth status` → JSON(`loggedIn`, `authMethod` 등). 이메일·조직 정보도 나오지만 저장하지 않는다.
- `claude auth login` (기본: 구독 로그인), `--console`(API 과금)
- 공식 설치: `curl -fsSL https://claude.ai/install.sh | bash` → `~/.local/bin/claude` (macOS 13 이상)

## 검증

- 각 항목 단위 테스트, 되돌리기·기억은 실제 CLI 통합 테스트
- 기존 단위·통합 테스트 회귀
- 화면 캡처 검증

## 실행 이력 (2026-11-24)

- 3 되돌리기: `checkpoint.rs` 숨긴 저장소(앱 데이터 `shadow/project-<id>.git`, 작업 폴더 = 사용자 폴더). DB v9 `checkpoints`. 대화 응답 전후 스냅샷, 되돌릴 때 이후 사용자가 고친 파일은 건너뜀. 실측 `live_대화_되돌리기` 통과.
- 4 쉬운 말 승인: `src/plain.ts` (설명·위험도·권한 3단계), 설정 "개발자 모드"에서만 원래 명령 펼침.
- 5 팀원 기억: `memory.rs`, DB v10 `agents.memory`. 보고의 `## 기억할 점`을 모델 호출 없이 흡수, 2000자 상한. 실측 `live_팀원_기억` 통과.
  - 관찰: 팀원이 Claude Code 자체 자동 기억(`~/.claude/projects/...`)에도 쓰는 경우가 있음 (런타임 기본 동작).
- 6 분야별 팀: 템플릿 `team` (개발·문서·법률·디자인·자동화·조사), 문서·법률(참고용 고지)·디자인·자동화 템플릿 추가, 팀 화면 팀별 묶음, PM 팀 요약에 [팀].
- 7 사장 캐릭터: 설정 키 `boss`(이름·외형·색), `office::pending_requests`. 사무실 사장 자리·대기 요청 수 말풍선, 사장 패널(요청 목록 클릭 → 대화/작업 이동, 꾸미기).
- 8 설치·로그인 안내: `setup.rs` — `claude auth status`에서 `loggedIn`·`authMethod`만 역직렬화, 공식 설치 스크립트 실행, `claude auth login` 중계(주소 표시·코드 입력). 설치·로그인 안 됐을 때만 첫 화면에 표시, "나중에 하기" 가능. 실측 `live_설치_로그인_상태` 통과.
  - 미검증: 실제 설치 스크립트 실행·로그아웃 상태 로그인 흐름 (개발 환경 계정을 건드리지 않기 위해 실행하지 않음).
